RAX — Scaling Online Exploration for Robot Agents
English weekly-meeting presentation

OPEN
Open index.html in a current desktop browser. Keep the assets folder beside it.
The presentation, fonts, videos, Method animation, and interactive 3D model work
offline. No installation or local server is required. To move the presentation,
extract the complete ZIP and open its index.html.

CONTENTS
36 main slides with a suggested total speaking time of 30 minutes, followed by
19 technical backup slides. Speaker notes contain explanations, timing, and
evaluation conditions. Step-by-step builds let one slide support several points.
The cover leads directly into the background. A short paper summary is available
in the technical backup.

Suggested pacing: background, problem, and related work 4.5 minutes; method 7 minutes;
evaluation 9 minutes; mechanisms 4.5 minutes; reuse and adaptation 3 minutes;
discussion 2 minutes. Concise speaking cues precede optional technical detail.

The paper's main Figures 1–12 are represented through complete figures or
relevant panels. Selected appendix figures clarify geometry estimation, dexterous
grasping, failure patterns, layout adaptation, and real-robot implementation.
Results use tables extracted from the paper; figures and table values are not
redrawn. Click a figure or table to enlarge it; some open a fuller source figure.

Benchmark results pair numerical evidence with matching visual context:
- BEHAVIOR: RAX boxing-books replay (3 of 6 books, Q = 0.5 in this example).
- Humanoid: RAX DoubleDesk action-free example; the main comparison instead
  provides three action demonstrations. Visual demonstrations remain available.
- DexJoCo: RAX bimanual Tower of Hanoi execution.
- RoboDojo: task reference demonstrations, explicitly identified as reference
  footage rather than RAX evaluation rollouts.
- LIBERO: paper images show the changed layout and resulting program repair.

Official Method animation (slide 8): select a stage, play/pause, or replay.
The next slide step switches to the architecture figure.
Interactive 3D model (slide 10): drag to orbit, scroll to zoom, adjust the drawer
slider, and toggle the model layers. The next step shows the geometry estimators.
These modules pause when hidden. After interacting inside a module, click the
slide margin and use the arrow keys to continue the presentation.

Short demo cuts retain the source video's timing and speed annotations.
They are qualitative, often accelerated examples, not real-time execution
measurements or estimates of benchmark success rates. Playback is silent.

TYPOGRAPHY
Source Serif 4 Semibold for titles; Source Sans 3 for body text. Labels use normal
tracking and sentence case. Embedded fonts do not require installation.

The presentation has no bottom toolbar; navigation uses the keyboard.
Interactive modules and native video controls can capture keyboard focus;
clicking the slide margin restores slide keyboard navigation.

PRINT
The browser Print command uses static figures and video posters. Speaker notes
and navigation controls are excluded. Present the HTML to use animation and 3D.
