# Scaling Online Exploration for Robot Agents — weekly meeting

An independent English research-paper presentation of RAX by Huang et al.

**[Open the presentation](https://sang-w00.github.io/rax-weekly-meeting/)**

31 main slides paced for about 30 minutes, with 4 technical backup slides.
The site includes paper figures and tables, short official demo excerpts, and
the project’s interactive Method animation and an automatic 3D air-fryer animation.

Use the arrow keys or Space to navigate. `F` opens full screen, `N` shows
speaker notes, and `O` opens the slide overview. Videos are muted; native playback
controls are available.

## Hosting

A static GitHub Pages site served from the `main` branch root. All runtime assets
are local and paths are relative, including the two interactive modules.
`.nojekyll` preserves the static file structure. No backend or installation is needed.

The full folder also works offline by opening `index.html`.
